              For your own reference. Customers never see it.
              
                    
              

                    
              
                        
                        
                        
              
                            A role is a fixed slot in the conversation, filled by one reply.
                        
              
                    
              

                    
              
                        
                        
                        
              
                            One per line. Matched by meaning, not exact words — three or four
                            varied phrasings work better than a long list of near-duplicates.
                        
              
                    
              

                    
              
                        
                        
                        
              
                            One reply per line. If you give several, one is chosen at random so the
                            bot does not sound like a recording. Use [NAME] markers for
                            values you set below.
                        
              
                    
              

                    
              
                        
                        
              
                        
                        
              
                            Fills the [NAME] markers above. Anything unfilled is left
                            visible in the reply, so you can spot it.
                        
              
                    
              

                    
              
                        
                        
                        
              
                            Higher means fewer, more certain matches. Raise it if this reply fires
                            when it should not.
